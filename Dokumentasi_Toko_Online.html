Gambaran Umum Aplikasi
Apa yang dibangun dan bagaimana cara kerjanya

Toko Online Sederhana adalah aplikasi web full-stack yang dibangun sebagai proyek pembelajaran. Aplikasi ini memiliki fitur manajemen produk lengkap (CRUD) dengan tampilan yang dapat diakses melalui browser.

🖥️
Frontend
Tampilan yang dilihat pengguna, dibangun dengan React + Vite
⚙️
Backend
Server & API yang memproses data, dibangun dengan Node.js + Express
🗄️
Database
Penyimpanan data produk menggunakan MongoDB (In-Memory)

Prasyarat (Persyaratan Sistem)
Software yang harus terinstal sebelum menjalankan aplikasi
⚠️
Penting Sebelum Memulai
Pastikan seluruh software di bawah ini sudah terinstal di komputer Anda sebelum melanjutkan ke langkah berikutnya. Tanpa software ini, aplikasi tidak dapat berjalan.
  • 🟢
    Node.js (versi 18 atau lebih baru)
    Runtime JavaScript untuk menjalankan backend. Download di: nodejs.org → pilih versi "LTS". Untuk memverifikasi: buka Terminal, ketik node --version
  • 📦
    npm (Node Package Manager)
    Sudah otomatis terinstal bersama Node.js. npm digunakan untuk menginstal semua dependensi (library). Untuk memverifikasi: ketik npm --version di Terminal
  • 💻
    Terminal (sudah ada di macOS)
    Aplikasi bawaan Mac untuk mengetik perintah. Buka melalui: Spotlight (⌘+Space) → ketik "Terminal" → Enter
  • 🌐
    Browser Modern (Chrome, Safari, Firefox)
    Untuk mengakses tampilan aplikasi. Gunakan Google Chrome untuk pengalaman terbaik karena memiliki developer tools yang lengkap.
💡
Tidak Perlu Instal MongoDB!
Aplikasi ini sudah menggunakan MongoDB In-Memory (mongodb-memory-server), sehingga database berjalan otomatis di dalam memori komputer Anda tanpa perlu instalasi tambahan. Data bersifat sementara dan akan ter-reset setiap kali server dimatikan.

Cara Menjalankan Aplikasi
Langkah demi langkah dari awal hingga aplikasi berjalan
📋
Anda Membutuhkan 2 Jendela Terminal
Backend dan Frontend harus berjalan secara bersamaan, masing-masing di jendela Terminal yang berbeda. Buka dua jendela Terminal: Terminal 1 untuk backend dan Terminal 2 untuk frontend.
1
Download / Dapatkan Kode Proyek
Pastikan folder proyek Online Shops Binus sudah ada di komputer Anda. Anda bisa mendapatkannya dari dosen atau teman melalui USB/email, lalu simpan di lokasi yang mudah diingat seperti folder Documents.
2
Install Dependensi Backend (Terminal 1)
Buka Terminal pertama. Masuk ke folder backend dan install semua library yang dibutuhkan:
Terminal 1 — Backend
# Masuk ke folder backend
cd "Documents/Online Shops Binus/backend"

# Install semua library yang dibutuhkan
npm install

# Output yang diharapkan:
# added 124 packages in Xs
3
Jalankan Server Backend (Terminal 1)
Di Terminal yang sama, jalankan server backend:
Terminal 1 — Backend
node server.js

# Output yang diharapkan jika berhasil:
# 🚀 Server backend berjalan di http://localhost:5001
# ✅ Berhasil terhubung ke Database Memori Sementara!
# ✅ Data produk dummy berhasil ditambahkan!
✅
Terminal 1 Jangan Ditutup!
Biarkan Terminal 1 tetap terbuka dan berjalan. Jika ditutup, backend akan mati dan frontend tidak bisa mengambil data produk.
4
Install Dependensi Frontend (Terminal 2)
Buka jendela Terminal baru (Cmd+N atau Cmd+T). Masuk ke folder frontend dan install library:
Terminal 2 — Frontend
# Masuk ke folder frontend
cd "Documents/Online Shops Binus/frontend"

# Install semua library React
npm install

# Output yang diharapkan:
# added 56 packages in Xs
5
Jalankan Server Frontend (Terminal 2)
Di Terminal 2, jalankan server development React:
Terminal 2 — Frontend
npm run dev

# Output yang diharapkan:
# VITE v6.x.x ready in XXX ms
# ➜ Local: http://localhost:5173/
# ➜ Network: use --host to expose
6
Buka Aplikasi di Browser 🎉
Buka browser (Chrome/Safari) dan kunjungi alamat berikut:
Browser Address Bar
http://localhost:5173
🎊
Aplikasi Berhasil Berjalan!
Anda akan melihat halaman beranda Toko Online Sederhana. Klik "Lihat Produk Kami" untuk melihat daftar produk yang sudah tersedia secara otomatis.

Dokumentasi API Backend
Daftar endpoint yang tersedia di server

Berikut adalah daftar URL API yang disediakan oleh backend. Setiap endpoint bisa dicoba menggunakan browser (untuk GET) atau aplikasi seperti Postman (untuk POST, PUT, DELETE).

Base URL: http://localhost:5001

Method Endpoint Fungsi Operasi CRUD
GET /api/products Mengambil semua data produk Read (List)
GET /api/products/:id Mengambil detail satu produk berdasarkan ID Read (Detail)
POST /api/products Menambah produk baru (support upload gambar via multipart/form-data) Create
PUT /api/products/:id Mengubah data produk yang ada (support upload gambar baru) Update
DELETE /api/products/:id Menghapus produk berdasarkan ID Delete

📦 Format Data Produk

Setiap produk memiliki struktur data berikut:

Troubleshooting (Mengatasi Masalah Umum)
Solusi untuk masalah yang sering terjadi
❓ Halaman produk kosong / tidak ada data produk yang muncul
Kemungkinan server backend belum berjalan. Pastikan Terminal 1 masih terbuka dan menampilkan teks 🚀 Server backend berjalan di http://localhost:5001. Jika sudah tertutup, buka ulang Terminal, masuk ke folder backend, dan jalankan node server.js lagi.
❓ Muncul error "command not found: node" di Terminal
Node.js belum terinstal di komputer Anda. Kunjungi nodejs.org, download installer versi LTS, dan ikuti proses instalasinya. Setelah selesai, tutup dan buka kembali Terminal, lalu coba lagi.
❓ Port sudah digunakan / Error "EADDRINUSE"
Ada proses lain yang sedang menggunakan port yang sama. Coba hentikan semua Terminal yang berjalan, tunggu beberapa detik, lalu jalankan ulang. Atau restart komputer Anda. Catatan khusus Mac: Port 5000 digunakan oleh sistem AirPlay Apple, oleh karena itu backend ini menggunakan port 5001.
❓ Gagal upload gambar produk baru
Pastikan: (1) Anda benar-benar telah memilih file gambar melalui tombol "Choose File", (2) Server backend sedang berjalan (Terminal 1 aktif), (3) Format file gambar yang diunggah adalah JPG, JPEG, atau PNG.
❓ Data produk kembali ke awal (data yang ditambah hilang)
Ini perilaku yang normal pada aplikasi ini. Karena menggunakan MongoDB In-Memory, data hanya tersimpan selama server backend aktif. Setiap kali server dimatikan dan dihidupkan kembali, data akan kembali ke data dummy awal (3 produk contoh). Untuk menyimpan data secara permanen, diperlukan instalasi MongoDB lokal atau koneksi ke MongoDB Atlas (cloud).
❓ npm install gagal / banyak error merah
Pastikan Anda menjalankan npm install di dalam folder yang benar (backend untuk backend, frontend untuk frontend). Coba hapus folder node_modules jika ada, lalu jalankan npm install lagi. Pastikan juga koneksi internet aktif karena npm perlu mengunduh library.
